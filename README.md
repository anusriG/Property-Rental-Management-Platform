# Property Rental Management Platform

## 60-Day Capstone Project

### Domain
Real Estate / Property Management

### Objective
Build a web application where property owners can list rental properties, customers can search and request rentals, and administrators can manage users, properties, and rental activities efficiently.

### Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Spring Boot (Java)
- Database: MySQL

### Project Status
Project planning completed.
The Property Rental Management Platform is a full-stack web application that helps property owners list their properties and allows customers to search and rent properties easily. The platform provides a centralized system for managing rental listings, booking requests, and user information.
