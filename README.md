# Property Rental Management Platform

## 60-Day Capstone Project

### Domain
Real Estate / Property Management

### Objective
Build a web application where property owners can list rental properties, customers can search and request rentals, and administrators can manage users, properties, and rental activities efficiently.

### Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Spring Boot (Java)
- Database: MySQL

### Project Status
Project planning completed.
