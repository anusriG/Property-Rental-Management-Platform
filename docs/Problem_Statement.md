# Property Rental Management Platform

## Overview

The Property Rental Management Platform is a web-based application that connects property owners and customers looking for rental properties. It provides a simple and secure platform where owners can list their properties and customers can search and request rentals.

---

## Problem Statement

Finding rental properties is often difficult because information is scattered across different platforms, and property owners struggle to manage inquiries manually. Customers spend a lot of time searching for suitable houses, while owners have difficulty reaching genuine tenants. This project aims to provide a centralized platform that simplifies the rental process for both owners and customers.

---

## Proposed Solution

The proposed system allows property owners to register, add and manage their properties. Customers can register, search for properties based on their preferences, and send rental requests. An administrator manages users, property listings, and monitors the overall platform.

---

## Objectives

- Simplify the property rental process.
- Connect owners and customers on a single platform.
- Reduce manual work.
- Improve property search efficiency.
